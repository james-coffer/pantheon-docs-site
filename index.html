About this project

Pantheon Docs is a personal, single-user documentation system. It organizes technical notes as plain-text Markdown files so they can be searched, versioned, and retrieved without loading an entire knowledge base.

The owner uses rclone and Google Drive to maintain a copy of these files between personal computers. The system is not offered as a public service and does not accept registrations.

Google Drive authorization

Google OAuth allows the owner to authorize rclone to read and write Drive files. The intended workflow is limited to the owner's chosen documentation folder, although the permissions granted to rclone may technically cover other Drive files. All transfers are controlled by the owner's configuration and commands.

This informational website does not connect to Google Drive, collect access tokens, or host the owner's private documentation. See the privacy policy.
