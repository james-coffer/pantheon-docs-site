PANTHEON DOCS

Privacy policy

How this personal documentation synchronization project uses Google Drive.

HomePrivacy policy

Effective: October 17, 2026

Overview

Pantheon Docs is a private, single-user workflow using the open-source rclone utility to transfer project documentation between the owner's devices and the owner's own Google Drive account. It is not a hosted product and does not accept users or collect information from the general public.

Google data accessed

When the owner authorizes access through Google OAuth, rclone can retrieve Drive file content and metadata (including file and folder names, paths, sizes, and modification times) and perform authorized transfers and updates. Operations are intended for the documentation folder. Some OAuth permission scopes can enable broader Drive access even when the configured workflow uses only that folder.

Purpose and use

Google data is used solely for owner-directed file listing, copying, synchronization, comparison, and restoration. It is not used for advertising, profiling, or sale.

Storage and sharing

Documentation remains in the owner's Google Drive and on the owner's devices. Rclone stores OAuth access and refresh tokens in its local configuration file, subject to local device security. The project does not operate a public service receiving Google Drive content and does not intentionally disclose Google Drive data to unrelated third parties. The Google Drive API and Google Drive storage remain subject to Google's own policies.

Owner control

The owner controls which files rclone transfers and can revoke the authorization at any time in Google's account security settings. This website does not ask for Google passwords or OAuth tokens.

This website

The public informational pages are hosted by GitHub Pages. They contain no project-specific tracking scripts, forms, cookies, or advertising. GitHub may process routine request data under its own privacy policies to deliver the site.

Changes and contact

Policy updates will be published here with an updated effective date. Questions may be directed to the project owner through the GitHub account associated with this website.
